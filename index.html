Strawberry Fields: Handwritten Plant-Tag Digitization

Every plant carries a tag with its ID, planting date, barcode, organisation and a handwritten weight log updated every few days. At harvest, staff copied all of it by hand. We replaced that with a tablet app: snap the tag, review the pre-filled record, confirm and push to the database.

96%
accuracy across all fields, handwriting included
−40%
harvest documentation time
2
custom YOLOv8 models in sequence
  • Tag detection with orientation: trained YOLOv8-OBB to find tags at any rotation and de-skew them before reading.
  • Field-level reading: a second YOLOv8 detects each field (ID, date, barcode, org, weight entries); every crop goes through Google OCR and is mapped back to its field.
  • Human-in-the-loop: a tablet UI built into the client's website lets workers verify, correct and commit records straight to their DB.

Specimen Tray Placement Verification

Specimen shells must sit in their designated slot on a six-position tray, and a person used to check every placement by eye. The system reads the shell label and the slot label, then flags any mismatch and shows where the shell belongs.

6
slot positions checked per tray
Auto
flag + correct slot shown
  • Stage 1: YOLO detects each specimen box together with the slot label printed below it.
  • Stage 2: a fine-tuned YOLO isolates both labels in each crop; Google OCR reads them.
  • Decision: name and position must match the slot, or the shell is flagged.
